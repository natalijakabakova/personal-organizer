PERSONAL ORGANIZER v0.3 — бизнес-дизайн сине-зелёный, тёмно-синяя панель.

РАЗВЁРТЫВАНИЕ
1. Распакуйте архив.
2. Загрузите файлы ИЗ папки personal-organizer-v0.3 в корень репозитория GitHub Pages (index.html, sw.js, manifest.webmanifest, icon-*.png, icon.svg).
3. В GitHub: Settings → Pages → Deploy from a branch → main / (root).
4. Откройте опубликованный сайт в Safari → Поделиться → На экран Домой.

ЕСЛИ ОБНОВЛЯЕТЕ С v0.2
Замените ВСЕ файлы в прежнем репозитории, не создавая новый. Данные из v0.2 останутся, если домен и путь сайта не изменились и не очищено хранилище Safari. Перед обновлением желательно иметь резервную копию данных.

ВОЗМОЖНОСТИ
• Календарь, события, To-Do с фильтром даты и диапазона, заметки на весь экран с форматированием, папками, закреплением, чек-листами, таблицами и ссылками.
• Напоминания из заметок показываются на экране Сегодня после наступления времени (НЕ являются push-уведомлениями).
• Бюджет — локальные записи и CSV для импорта в Google Sheets. ПРЯМАЯ запись в Google Sheets пока не реализована.
• Резервное копирование и восстановление в JSON на главном экране.

ВАЖНО: все данные пока локальны для конкретного браузера/устройства. Не удаляйте данные Safari без резервной копии. Push-уведомления и автоматическая синхронизация с Google Sheets требуют отдельной настройки.
