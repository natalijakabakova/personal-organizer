PERSONAL ORGANIZER v0.1 — первый рабочий прототип

Файлы для GitHub Pages: index.html, manifest.webmanifest, icon.svg, sw.js.

1. Создай ОТДЕЛЬНЫЙ репозиторий, например personal-organizer.
2. Загрузи в корень репозитория все четыре файла.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Открой ссылку GitHub Pages в Safari на iPhone.
5. Safari > Поделиться > На экран «Домой».

Работает: календарь с событиями, добавление/редактирование/удаление; задачи и отметки выполнения; заметки; локальный журнал доходов/расходов; экспорт CSV; локальное сохранение данных.
Не работает пока: серверные push-напоминания; автоматическая запись в Google Sheets; синхронизация между устройствами.

ВАЖНО: локальные данные привязаны к конкретному браузеру и сайту. Очистка данных браузера может удалить записи. Не используй для единственной копии важной информации до добавления резервного копирования и синхронизации.
